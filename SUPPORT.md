# Support

## Product help

Start with the documentation at [sitecmd.com/docs](https://sitecmd.com/docs). For account, billing, installation, or product questions, use the [SiteCMD contact form](https://sitecmd.com/contact) or email `support@sitecmd.com`.

Do not send source code, credentials, private URLs, scan findings, or customer data unless support specifically requests a safe, minimized example.

## Bugs and feature requests

Use public GitHub issues for reproducible product bugs and feature requests that do not contain sensitive information. Search existing issues before opening a new one.

This repository does not currently accept unsolicited code contributions. See [CONTRIBUTING.md](CONTRIBUTING.md) for the current policy.

## Security

Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
